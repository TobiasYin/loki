# 语音上下文验收

2026-10-17，AYN Thor / Android 13，真实保存的火山 ASR 配置和设备网络。

- `physical.json`：真实 ASR、上下文来源、权限、会话隔离与提交语义的安全布尔/数值报告。
- `instrumentation.txt`：最终 `PhysicalVoiceContextTest` 通过记录。21.607 秒，1 项通过。
- `preservation.json`：原有 189 个会话、200 条 Run、400 条消息、63499 条事件、249 个附件及所选会话所有列一致；四份保存配置字节一致；安装 APK 与固定构建哈希一致。
- `apk-sha256.json`：验收 APK 的 SHA-256。私有数据库、凭据、用户原文和网络正文均未复制到本目录。
- `software.json`：软件校验汇总。

录音使用已有火山 TTS 固定样本 `tests/fixtures/volc-voice/03-game-mixed.wav` 提取的 PCM；没有录制用户麦克风，没有调用模型或执行 Agent 任务。验收只创建两个自有合成会话，结束已删除并恢复原选择。

上屏为实际启动器，标题与应用名相同，按规则去重；本轮不声称验证了游戏内标题读取，也不声称已通过对照语料量化识别率提升。之前三次未完成云识别的尝试均在上屏来源检查前后结束，原因是测试没有等待无障碍系统服务连接；最终测试显式等待系统连接再验证完整来源，实际聊天录音的 250 ms 降级预算不变。原始失败日志仅保留在本地忽略的 build 目录。

软件校验包括语音上下文与传输 38 项、网络 Bridge 42 项（Transport 21 项），以及构建与 lint。网络并发测试保持 8 条响应 body 未结束，确认所有响应均已收到 headers；第 9 条仍被拒绝，取消后可释放容量。
