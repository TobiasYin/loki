# 显式停止边界：源码测试证据

本目录固定 2026-10-17 停止边界补丁冻结后的源码测试时点。Runtime **115/115** 通过，失败、取消、跳过和 todo 均为 0；集成 TypeScript 检查退出码 0，日志为空表示编译器成功无输出。6 项为新增停止边界回归。未执行 Gradle、云模型、模拟器或 Thor 操作。

新增测试使用真实 Pi 与 provider SDK，覆盖 provider `next()`／`result()` 不结束、三协议部分 SSE 的读取／取消不合作，以及请求体序列化不返回。三协议先成功执行工具，再停止流，验证真正 Pi 已 idle、部分文字和工具上下文保留、同 Agent 追问、终态后无晚到写入及无工具重放。其余 109 项沿用完整回归，包括页面变化恢复和原有撤权／持久化边界；本次完整套件实际重新运行。

**本目录不证明 game11 真机卡住的具体原因已经复现或修复。** 普通停滞 SSE 原先就可正常停止。新增的是有确定回归的取消边界及下一轮定位所需的安全诊断；未加入模型总时限，未用跳过持久化或丢弃仍活跃 Pi 的方式报告终态。

[设计和诊断说明](../../../docs/stop-boundary-diagnostics.md) 解释两项 DEBUG 入口、返回边界和使用限制。`summary.json` 含 Runtime、provider-stop、集成宿主、新测试和依赖锁的字节数／SHA-256；另含父任务冻结的 Native ProductHost 与物理观察器接口源文件哈希。这两个 Kotlin 文件在本目录仅固定接口配套时点，不声称已通过 Android 构建或设备验收。

`runtime-node.log` 和 `integration-tsc.log` 是成功命令的原始软件日志复制，只含命令、测试名及结果，没有原始模型思考、完整对话、SSE 正文、凭据或设备数据库。文档和 `summary.json` 还记录诊断上限、等待阶段以及 Native 缓存采样可能落后一轮的限制。

`manifest.json` 仅覆盖本目录除自身之外的文件，以 `path`、`bytes`、`sha256` 校验；没有更新共享的上层清单。最终 APK、Gradle、模拟器和真机证据将由后续独立验收记录，不能把本轮 Node 结果直接套用为设备通过。
