# 游戏验收证据的公开范围

`progress.json` 保留原始验收进展、失败及恢复范围，不把未完成的游戏任务改写为通过。

三张原始游戏截图已从公开 `main` 和对应历史中移除，避免公开存档名称及未经确认分发范围的第三方画面。`withheldScreenshots` 仅记录私有原始截图的文件名、SHA-256 和当时的观察范围，不代表公开仓库存在这些图片。`screenshots` 为空。

原始文件保存在仓库外的私有重写前备份中。其他公开文件的变化记录见 [publication-redactions.json](../../publication-redactions.json)。删除截图不构成重新执行验收，也不增加历史测试的证据资格。
