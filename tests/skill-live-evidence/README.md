# Agent 自建星露谷 Skill：真实模型验收

日期：2026-10-16。结论：**创建、持久化、挂载、命中与按需读取的能力链路通过；攻略答案准确性没有全部通过。**

使用 Android 16 AVD、真实 OpenCode Go Responses / `deepseek-v4.1-flash`、Brave 和 Stardew Valley Wiki。未操作物理 Thor，也没有启动星露谷游戏。测试程序没有预置攻略答案或代写 Skill；保存批准由 instrumentation 点击实际产品 UI，不能称为真人批准。

## 测试结果

| 项目 | 结果 |
|---|---|
| 自行研究和保存 | Agent 自行搜索并读取资料，建立 `stardew-valley-guide`，随后从失败会话继续并修订；单个目录、3 个文件 |
| 持久化 | 宿主重建后文件 hash 一致，新会话能选择该 Skill |
| 无关题 | 17×23 回答 391，没有读取攻略正文或参考文件 |
| 未挂载对照 | 目录只列出三个内置 Skill，没有读取或声称挂载该攻略 |
| 鲶鱼题 | 自动读取正文和 `references/rainy-catfish.md`；河流、时间、竹竿槽位、保留鲶鱼的主建议正确，但额外建议春天留意 Tiger Trout 错误 |
| 春 19 补种题 | 自动读取正文和 `references/spring-crops-bundle.md`；10 天、春 18 最迟、春 19 来不及正确，但额外把旅行商车称为非随机途径，违反题设 |
| 已持有装备对照 | 只读正文与钓鱼/装备专题；正确回答 2 级玩家已经持有 Iridium Rod 和 Trap Bobber 时可以装备，购买/制作条件不等于使用条件 |
| 按需加载 | 首次实际 HTTP 请求不含任一 Skill 文件全文；主动读取后，后续请求才包含对应文件；未读取的另一专题从未进入模型请求 |
| 失败后继续 / 追问 | 旧失败回合的网页、保存结果保留，真实继续请求与同 Pi Agent 追问均 HTTP 200，没有重新执行工具 |
| 新会话继承 | 新建会话继承上一会话的 Skill 选择，历史保持独立 |

鲶鱼题的错误扩展可对照 [Tiger Trout 条目](https://stardewvalleywiki.com/Tiger_Trout)：在本题无魔法鱼饵的条件下，其普通季节为秋、冬。作物题额外建议可对照 [Traveling Cart](https://stardewvalleywiki.com/Traveling_Cart) 和 [Speed-Gro](https://stardewvalleywiki.com/Speed-Gro)；“完成 Bundle 有奖励”不能推出“只能从这个奖励获得”。原题已经排除了肥料和随机商店，这些扩展没有必要，也不符合约束。

## 原始证据与资格

最终五类独立会话来自第 15、17 轮，同一 App APK、同一不可变 Skill 修订。第 15 轮在鲶鱼回答后被措辞断言中断：断言没有识别“装不了”，但此前全部 Skill 读取和请求隔离检查已通过；该错误没有被改写为整个套件通过。第 17 轮完成作物、装备两项流程，`OK (1 test)`，并核对继承选择。两个内容错误均单独记录为准确性失败。

第 7 轮曾实际保存 Skill，但回复受到旧整轮时限中断；第 8 轮从原研究上下文继续完成保存。随后发现 Pi 系统记录影响消息位置计算，导致追问缺失并返回 HTTP 400，修复后第 11 轮的继续和同会话追问均成功。第 12、13 轮由 Agent 自己联网核查装备前提、保存并精简修订。作物专题在修订中保持字节不变。

完整原始报告与 HTTP 请求体保存在本机忽略目录 `build/integration/skill-live-attempt-*/`；本目录不收录思考全文、凭据或完整抓包。`summary.json` 保存其哈希及明确的失败原因，区分产品错误、测试程序时序/措辞问题与模型事实错误。运行器只接受 `emulator-*` 并验证 qemu；当前版本会固定待安装 APK、记录源文件哈希并只收集本轮请求。

## 随测试修复的代码

模型和普通整轮任务不再设置时间上限，单工具仍可超时；取消一个工具不再撤销整轮授权。每个会话复用 Pi Agent，失败回合保留已取得的消息/工具结果，旧失败记录可从 Native 事件恢复；未知结果不自动重放。修复了复用时把当前追问截掉的计数问题、多文件保存参数层级易错、长流式输出积压造成 V8 OOM，以及网页脚本噪声占满正文预算。

软件检查：77 项 JS、210 项 JVM、Lint、debug/release/test APK 和产物隔离通过。隔离 AVD 报告 22 项，其中 21 项执行通过、1 项 Shizuku 条件跳过，另 4 项接收端解析检查通过。一次真实模型响应到下一请求的间隔约 271 秒，超过旧三分钟限制后仍正常保存并完成。

测试结束后通过实际产品 UI 恢复联网搜索，保留选中的攻略 Skill，全部 Run 均已终结。模拟器用户数据与凭据保留，关闭本轮专用模拟器；真机测试仍暂停。
