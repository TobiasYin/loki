# 星露谷春季专题（1.6 普通社区中心）

## 适用条件
- 版本 1.6，普通（非混合 Remixed）社区中心路线。
- 只覆盖上述两个专题；其他季节、其他 Bundle、混合 Bundle 不在范围内。

## 先确认状态（给建议前必做）
- 游戏版本、是否混合 Bundle（本 Skill 只对普通 Bundle 有效）。
- 当前季节与日期（春 1–28）、天气预报是否为雨、仓库已有物品、金卷轴进度。
- 钓鱼：当前实际持有的鱼竿、钓鱼等级、背包里的 bait（鱼饵）与 tackle（钓具）。

## 步骤与读取
- 春季作物献祭与补种期限 → 读 references/spring-crops-bundle.md
- 雨天鲶鱼安排与钓具装备前提 → 读 references/rainy-catfish.md

## 给方案的方式
- 先按玩家**当前实际持有的鱼竿**判断能否装 bait/tackle（槽位只看鱼竿，不看等级），再给当前可执行的动作。
- 当前鱼竿装不了时，给现在就能做的替代动作；确实需要购买或升级鱼竿时，才说明购买解锁条件（等级、金币）。
- 不要把买不起/装不上的道具列为可选方案。

## 核验
- 献祭：在社区中心金卷轴内确认 4 种作物已逐项放入。
- 补种：按“最晚播种日”核对；生长天数不含播种当天，播种日 + 生长天数 = 收获日。
- 鲶鱼：确认当天为雨天、6:00–24:00、钓点为河流/秘密森林，钓到后放入 Fish Tank 的 River Fish Bundle；若建议了 tackle，再确认所用鱼竿有 tackle 槽位。
