## 依赖与停止条件

M1a 先建立独立上屏接收器并完成 POC-11，M1b 使用它证明真实手柄和配置路径，避免完成 UI 后才发现核心操作不成立。各阶段可以调整内部顺序，但不跳过授权撤销网关。模型/搜索账户缺失时可做契约测试，不能标记真实端点兼容通过。

手柄无 Root 不成立：交付失败证据、评估受限功能/厂商支持/明确 Root 备选，由用户做范围决定；不擅自删去手柄要求。配置路径私有不可达：通过模拟器导出/导入路径或只读建议保持价值，不承诺万能配置编辑。

WebView 链路失败：可尝试固定兼容版本/缩小入口/最小兼容层；如果必须替换运行引擎，更新 ADR-002，仍保持模型协议在 Pi/JS 层。不能直接改成 Native 实现 Responses/Anthropic。

## 下一阶段开始前需要的资料

实际 Thor SKU、系统/固件/WebView；两个优先模拟器与配置使用方式；可测试的模型 endpoint（密钥仅通过未来安全设置输入）；搜索后端偏好；四张原始 UI 图。资料未齐可以继续完善文档，开发/装依赖/构建不在本次任务授权内。
