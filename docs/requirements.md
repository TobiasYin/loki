## 非功能目标（暂定预算）

- 每设备同时一个活动 Run；跨 Session 操作串行，避免上下文和焦点互相覆盖。
- L0 序列化文本目标 ≤1 KiB；工具定义、对话历史和图像费用单独计量，不伪称固定 token 数。
- UI 点击停止后立刻显示“正在停止”；Native 收到撤销后，所有尚未开始的旧授权操作零放行。针对可取消操作，目标 1 秒内发出终止/释放并回报状态；已提交系统调用不保证可撤回。
- 文本结果、截图、队列和网络均有硬上限；具体初值见工具及网络设计，达到限制必须返回 truncated 或明确失败。
- 空闲不自动截图、不持续遍历 UI 树、不轮询日志；只有轻量应用变化监听在感知开启时工作。
- 背景耗电、游戏帧率影响、端到端延迟没有测量结果。POC-10 建立基线后冻结预算，不在此宣称“无性能影响”。

## 文档阶段验收

结构有明确职责、需求均有验收与验证入口、关键 API 有官方引用、事实和假设分开、未生成任何功能源码/依赖清单/构建文件。所有 PoC 保持未执行，缺图和机型信息缺失列入开放问题。
