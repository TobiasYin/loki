# 测试策略与发布验收

## 当前状态

仅完成文档结构/链接/一致性审查，不存在实现测试结果。后续测试按真实边界设计，避免只测试“常量等于常量”或把 mock 成功当实机兼容证明。

## 统一上屏测试接收端

[Thor Input Lab](input-lab.md) 是手动 API 与 Agent 端到端输入/感知回归的共同必备测试依赖。先在 POC-11 校准接收器，再运行 POC-01/02/05/06/07/10 的相关 LAB 用例；POC-08 先用其合成配置，再验证真实模拟器。网络/搜索仍保留独立测试服务，不要求 Lab 冒充这些后端。

结果必须关联调用端记录、接收端原始事件和场景变化。场景版本/布局种子/断言/容差相同才能比较两阶段结果。手动平台直调、手动产品网关、物理基线和 Agent 四种模式明确区分；只有经过产品网关的路径能验证能力隔离。

没有事件不自动等于权限阻断成功：需健康接收、无日志缺口、完整观察窗及 Native 阻断记录。事件源信息不能可靠认证输入发送者；单活动 attempt、时间窗和污染标记保证关联边界。控件 semantic click 不计触摸注入通过。

## 分层验证

| 层 | 重点 | 代表案例 |
|---|---|---|
| 文档/契约审查 | schema、来源等级、需求覆盖、权限矩阵 | 每工具都有 capability、错误、取消、预算和验证 |
| Runtime 逻辑 | 投影、工具集合、事件归一、预算 | 关闭后历史系统声明不复活，tool call/result 完整 |
| Native 网关 | lease、epoch、系统授权和资源 | 伪造 Session、撤销竞态、直接绕桥路径 |
| Fetch 契约 | SDK 使用的 Fetch 子集、流、背压 | headers 后解析、任意 chunk 边界、HTTP 错误 body、abort |
| 数据层 | 事务、去重、迁移、故障恢复 | intent 已保存但结果缺失、进程终止、磁盘满 |
| 独立接收器资格 | 物理基线、反例、日志完整性、控制通道隔离 | POC-11：漏样本、错误 source、语义点击、失焦释放、重启不能伪通过 |
| Android 实机 | 两屏、窗口、截图、输入、Shell | 下屏 IME、目标切换、Shizuku binder 死亡 |
| 端到端 | 两协议完整任务和 UI 语义 | 问版本不截图；截图解释；配置恢复；手柄闭环 |

## 最小测试矩阵

设备：仅 Thor，但记录支持的 SKU/固件/WebView 组合，不能一台固件通过就覆盖所有 Thor。权限：16 种能力开关组合；无障碍开/关；Shizuku 未装/未启动/未授权/就绪/中途断开；搜索未配/错误 key/可用/离线。

焦点：下屏输入法开/关、上屏游戏/设置/系统弹窗、安全窗口、显示重建。模型：两种协议，各有图片＋工具成功路径及不支持能力的失败端点。数据：新会话、长历史、附件过期、摘要、删除、崩溃恢复。

不穷举不可承受的笛卡尔积；优先覆盖授权边界组合和高风险交叉场景。跨协议的图片工具回传、撤销和配置变更是强制项。

## 场景验收清单

- REQ-03/04：默认请求无截图、版本、UI 树；问版本只查 app_info；画面任务才出现 capture_screen。
- REQ-05/06/19：注入集合、最终模型声明和 Native effective set 一致；任意 Shell 不可通过 input pack 获得。
- REQ-07/08：图片/工具双向完整；网络取消和异常没有半成品工具执行；Native 无模型协议解析。
- REQ-10/11：上屏触摸坐标准确，真正手柄 source/axis/释放正确，下屏聊天不收到目标动作。
- REQ-12/13：权限身份真实；写前可恢复；并发冲突拒绝；Shell 限制说明可见。
- REQ-14/15/17：折叠不删除，重启不重放，摘要不拆工具配对，失败和未知副作用清楚。
- REQ-16/20：凭据跨 origin 阻断、桥隔离、调试跨能力边界文案一致。

- REQ-21～25：独立接收端、同一场景规范、原始事件与场景变化、受限控制面、缺口/重启/污染明确结论。

完整对应以 [需求表](requirements.md) 和 [PoC 表](poc-plan.md) 为准。

## 故障注入与指标

网络断开、服务端 429/500、数据块乱序/重复（桥应检测并失败）、无终止块、UTF-8 跨块、图片过大、队列溢出、工具超时、显示失效、授权 epoch 变化、运行目标切换、binder/renderer 死亡、磁盘满、数据库迁移失败。

记录首增量延迟、工具耗时、桥峰值缓冲、截图峰值内存、上下文估算与实计偏差、停止延迟、游戏帧率/电量变化。指标需要空闲基线和同一游戏场景重复测量；不要写“提升 x%”而无原始数据。

## 发布门槛

权限越界、凭据泄漏、误操作下屏、配置不可恢复覆盖、卡键和副作用自动重放为 P0，零未解决项。POC-11 接收器资格是相关输入测试证据的前置门槛；POC-03/04/05 为架构门槛；REQ-11 未通过时不得发布为完整四能力首版。若仅发布触摸实验版，必须另有范围批准并明示限制。

版本发布前冻结支持环境、依赖/许可证清单和安装更新流程；签名密钥保管、同签名升级/数据迁移/卸载提示在实际开发阶段验证。本次没有构建 APK，也不生成虚假安装说明或测试徽章。
