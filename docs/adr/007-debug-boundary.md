# ADR-007：任意 Shell 是明确的高权限通道

日期：2026-10-13。状态：已采纳（需求与安全边界）。

## 背景

ADB 调试包含 Shell 和文件；Shell 可执行其他能力对应动作。

## 决定

调试默认 OFF；Shizuku UID 需检查；结构化文件写提供差异/备份/恢复；Shell 命令单独展示批准，不能宣称强沙箱。

## 备选方案

黑名单隔离 Shell、Shizuku 等同 Root、任意文件必可达不采用。

## 后果与限制

其他能力开关不限制已授权 Shell；已发生副作用不能靠撤销回滚。

## 验证与重开条件

POC-08/05、REQ-12/13/20、Q-06。
