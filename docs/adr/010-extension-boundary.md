# ADR-010：首版内置 ToolPack、预留 MCP

日期：2026-10-13。状态：已采纳（范围）。

## 背景

需要可扩展，但首版过早插件化会扩大权限/依赖/维护范围。

## 决定

固定内置 Registry、版本化描述与执行契约；MCP 后续映射同一权限/结果预算边界。

## 备选方案

插件市场、远程 JS 热加载、首版通用 stdio 子进程管理不采用。

## 后果与限制

新增工具无需改 Agent 循环；MCP 的认证/传输/权限不能依靠名称猜测。

## 验证与重开条件

REQ-18；Q-17 有真实需求时另立 ADR。

依据与规范见 [官方参考](../references.md)、[需求验收](../requirements.md)、[PoC 计划](../poc-plan.md)。任何与已明确用户需求冲突的范围变化必须单独提出，不能由实现便利替代产品决定。
