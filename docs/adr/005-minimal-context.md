# ADR-005：最小 L0 与独立按需感知工具

日期：2026-10-13。状态：已采纳（需求）。

## 背景

自动图片/版本/UI 树消耗上下文并采集无关信息。

## 决定

默认仅设备类别、上屏应用和能力摘要；其他信息独立工具；L0 替换，感知关闭去动态应用信息。

## 备选方案

每轮截屏、全量环境快照、全局前台推断上屏均不采用。

## 后果与限制

需 display 映射、时效、坐标变换、按来源压缩；未知信息允许 null。

## 验证与重开条件

POC-01/02、REQ-03/04；Q-10。

依据与规范见 [官方参考](../references.md)、[需求验收](../requirements.md)、[PoC 计划](../poc-plan.md)。任何与已明确用户需求冲突的范围变化必须单独提出，不能由实现便利替代产品决定。
