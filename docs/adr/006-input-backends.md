# ADR-006：触摸与真实手柄分开验证

日期：2026-10-13。状态：条件性采纳，产品目标不变。

## 背景

跨屏触摸有公开接口；真实游戏手柄身份、轴和焦点不能由普通 keyevent 推定。

## 决定

触摸首选 Accessibility；手柄探索 Shizuku 受限输入执行器；可仅开启操作而不开放任意 Shell。

## 备选方案

键盘事件/屏幕点击冒充手柄、默认 Root、默认可用 uinput 不接受。

## 后果与限制

部分设备可能只支持触摸；必须如实展示可用性，不声称完整操作通过。

## 验证与重开条件

POC-06/07、Q-04/05/15；REQ-11 是完整首版门槛。
