# ADR-001：产品仅面向 Thor、独立分发和无 Root 优先

日期：2026-10-13。状态：已采纳（需求）。

## 背景

设备范围广会放大多屏、输入和权限差异；用户明确只支持 Thor。

## 决定

仅 Thor，下屏聊天，上屏目标；独立 APK 自行分发，不上 Play；优先 shell 身份的无 Root 方案。

## 备选方案

通用 Android 产品、系统应用、默认 Root 都超出范围。

## 后果与限制

仍要定义具体固件/WebView 支持矩阵；不承诺所有 Thor 固件一致。

## 验证与重开条件

POC-01、Q-01/15；手柄失败时另做范围决定，不自动 Root。

依据与规范见 [官方参考](../references.md)、[需求验收](../requirements.md)、[PoC 计划](../poc-plan.md)。任何与已明确用户需求冲突的范围变化必须单独提出，不能由实现便利替代产品决定。
