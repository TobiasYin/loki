# ADR-008：持久化领域模型与 UI/模型投影分开

日期：2026-10-13。状态：已采纳（设计）。

## 背景

工具轨迹有审计价值，但不必永久进入模型；折叠与压缩解决不同问题。

## 决定

Native 持有 Session/Message/Run/Event/附件，Runtime 生成版本化 ContextSnapshot；压缩保留工具配对和来源。

## 备选方案

直接存 Pi 内存对象、删工具日志实现折叠、每轮重传所有图像不采用。

## 后果与限制

需要投影和迁移逻辑；压缩失败应保守降级；断进程不重放操作。

## 验证与重开条件

POC-10、REQ-14/15/17、Q-14/16。
