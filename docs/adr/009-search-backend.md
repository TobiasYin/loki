# ADR-009：独立搜索 ToolPack 与显式后端

日期：2026-10-13。状态：候选采纳。

## 背景

模型协议兼容不代表有内置搜索，默认开关不能创造真实搜索结果。

## 决定

搜索默认 ON，后端就绪才注入；Brave 为首选验证候选；Tavily/SearXNG 为备选。

## 备选方案

抓取公共搜索页面作为无保障唯一后端、依赖模型厂商内置搜索、默认免费额度不采用。

## 后果与限制

首次需配置/测试；地区可达性、成本和中文质量决定最终选择。

## 验证与重开条件

POC-09、REQ-09，Q-07 尚未关闭。
