# ADR-004：动态工具注入与即时撤销

日期：2026-10-13。状态：已采纳（需求）。

## 背景

Prompt 不是权限隔离，模型已产生的工具调用可能晚于用户关闭开关。

## 决定

Session 持久化四能力；只注入 enabled 且 available 工具；Native epoch/Run lease 在副作用前检查；重新开启不恢复旧请求。

## 备选方案

仅 Prompt、仅 UI 禁用、仅 JS Registry 校验都不足。

## 后果与限制

需要可用性状态、取消句柄、资源锁和执行审计；有界并发。

## 验证与重开条件

POC-05、REQ-02/05/06/19；任何越权为 P0。
