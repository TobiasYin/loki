# Loki v0.1.0

首个 GitHub 公开发布版本，公开版本编号从 `v0.1.0` 开始。此前文档中的 0.3–0.8 是内部开发阶段记录，不能视为此前已发布的稳定版本。

- Android 应用：`com.tobias.loki`。
- 公开版本：`versionName=0.1.0`。
- Android 安装序号：`versionCode=10`，保留此前开发版本的升级顺序。
- 主项目许可证：MIT。第三方依赖及素材保留各自的许可证或权利声明。

## 功能范围

- 面向 AYN Thor 双屏掌机的聊天、模型选择、独立会话和后台任务。
- 支持 OpenCode Zen、OpenCode Go、DeepSeek、火山 AgentPlan 与自定义模型服务；凭据由 Native 保存。
- 支持上屏感知、按需截图、显式授权的屏幕操作及受限设备调试工具。
- 支持联网搜索、下载、Skill 管理和流式语音配置。

模型、搜索和语音服务需要用户自行配置并承担相应服务费用；部分设备能力依赖无障碍、Shizuku 与设备固件支持。现有硬件专项及游戏兼容性边界沿用各专题文档，不因此次公开版本编号重置而扩大。

## 构建与验收

使用根工程构建 `:app:assembleRelease`，正式产物来自 release 变体。APK 版本、调试开关、测试入口隔离、资产和签名信息应以本次实际产物校验记录为准。

发布标签为 `v0.1.0`，指向包含本次版本配置的提交。校验和随构建产物提供，不将本地签名私钥或服务凭据包含在源码和发布文件中。

本次构建验证：App JVM 268 项通过，Android Lint 通过；debug/release APK、AndroidTest APK 构建通过，实际 APK 的资源、运行时资产及 release 测试入口隔离检查通过。专用 `thor_agent_dual_api36 / emulator-5560` 上的 2 项真实 WebView 组件回归通过，使用 display 4 Context，上屏 display 0 / 1920×1080，下屏 display 4 / 1240×1080，均 369 dpi；Native 配置文件哈希保留。

模拟器使用保留数据更新的 v0.1.0 debug 包执行组件测试。发布 APK 单独完成 zipalign、签名及 release 内容校验；本次未以新发布签名覆盖设备上的 debug 应用，也未执行 Thor 真机验收。
