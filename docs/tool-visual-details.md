# 工具详情可视化（2026-10-18）

截图工具展开后直接显示该次调用返回的历史图片；点击、长按、滑动和拖动显示参考截图与工程绘制的坐标标记。坐标点击使用红圈，滑动和拖动使用路径，组件 `input.activate` 使用实际解析到的控件边界框，不伪造触摸点。网页搜索只展示搜索关键词，失败说明仍保留在对应工具内。

## 图片与标记关联

- Backend 在最终校验后、实际提交动作前记录显示坐标和来源截图。展示元数据放在独立 `ToolResult.presentation`，只写入 Native 的工具结果展示事件，不进入 Pi 工具内容、模型历史或输入权限判断。
- `frame_pixels` 使用实际校验的 frame；逻辑坐标和组件点击只匹配同一会话、运行、能力代次、显示、应用目标、触摸边界和显示代次下的缓存截图。显示坐标按截图裁剪与缩放变换映射到图片，再由 SVG 覆盖绘制，不修改原图。
- 图片标记表示提交位置或控件区域，不表示应用已完成预期效果。历史记录若只有显式 frame 参数，可按同一运行内先前截图精确还原；缺少可靠关联时显示说明，不拿任意近期图片代替。下屏只读 companion 图片不能作为上屏操作来源。

## 加载与生命周期

详情折叠时不读取图片；展开后通过固定同源只读路径 `/chat-images/<session>/<run>/<attachment>` 加载。收起工具或执行过程时移除图片节点及其 `src`。正常 UI 状态不携带 Base64 或私有文件路径。

Native 校验当前所选会话、运行和附件归属，拒绝探测运行、非法标识、过期记录、非截图来源和超过 2 MiB 的图片，并验证实际字节大小及哈希。图片响应禁止缓存。页面 CSP 只允许同源图片；网络、执行桥和文件访问权限没有扩大。文件被清理或读取失败时只在该工具详情内显示说明。
