# 截图历史与当前操作目标

Agent 的屏幕截图作为会话的历史数据保存到会话删除，避免长会话继续请求时，旧图在十分钟后突然被“图片已过期”占位符替换，改变先前模型请求中的历史前缀。新截图的 attachment 到期值使用 JavaScript 最大安全整数 `9007199254740991`；这个值是历史数据的保留标记。

对于旧版已经落盘的截图，读取时仅将返回副本的到期值规范到相同标记，原数据库行不迁移、不重写。仅允许同一会话、存在同一会话所属 Run、非配置探针、`image/jpeg` 且 source 仅为 `screen_perception` 的截图采用这一规则。用户上传、探针图、其他来源的附件保持原本到期行为。附件仍由 Native 按当前授权会话查询，并在返回前验证所有来源能力仍开启；撤销屏幕感知能力后不会因保留历史而继续获得图片。

保留图片不会延长任何可操作 frame、snapshot 或 nodeRef 的有效期。历史图只能用于理解已经发生的事情，不能证明当前页面状态，不能授权点击、键盘或手柄输入。Native `Snapshots`、新鲜观察校验、Run 目标屏幕校验及输入权限保持原有时效。模型继续操作时仍必须获取当前观察，使用新返回的操作目标。
