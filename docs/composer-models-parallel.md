# 0.5.0 紧凑输入区、模型资料与多会话

本轮依据用户提供的输入框参考图调整，只运行电脑端与 Android 模拟器验证。真机按用户指示保持暂停，不因此关闭既有硬件验收缺口。

## 页面行为

输入框使用两层布局：上层编辑文字或长按语音，下层依次为「+」、能力、模型/思考强度、麦克风和发送。发送在当前会话运行时变为停止，仅作用于当前会话；其他会话可继续运行，侧栏有对应标记。移除顶部活动横幅、切换不会停止的提示和配置检查成功通知。配置检查回合保留在 Native 审计中，从聊天消息投影隐藏。

「+」包含附图、当前会话 Skill 选择和 Skill 管理。内置创建/管理/设备手册保持可用，用户 Skill 按会话选择挂载，目录仍只携带元数据，正文及引用只有明确读取后才进入上下文。未挂载用户 Skill 的 Agent 正文读取会被拒绝；手动管理页面仍是独立的用户操作。

工具活动以无边框的简短文字和扫光动画呈现，思考与操作明细按需展开。失败、待批准和副作用未知等需要用户行动的信息保留。支持系统深浅主题和减少动态效果偏好。压缩布局仍保留 44 CSS px 的发送/停止点击区域。

## 设置与模型

设置首页分模型服务、联网搜索、语音输入、设备与权限，各分区是完整页面。语音设置不再出现在输入框。设置页面覆盖在原 Activity 内，打开、进入分区和返回不会暂停正在运行的 Runtime。连接密钥修改在活动运行结束后保存，密钥不传给 WebView。

模型服务支持 OpenCode Go 或自定义 API Key。Go 内置一份 Pi 1.2.0 的模型资料作为离线回退，可以从官方 npm 包发布目录刷新，并缓存成功结果；刷新失败保留原目录。来源为 `https://unpkg.com/@earendil-works/pi-ai@latest/dist/providers/data/opencode-go.json`。这是模型能力目录，不表示用户账号逐个模型已经实测可用。

任务页可选择模型和该资料声明、Pi 实际支持的思考强度。显式 null 的档位不展示；基本档位和扩展档位的处理与 Pi getSupportedThinkingLevels 一致。DeepSeek V4.1 Flash 的上下文为 1,000,000 tokens，思考强度为 low/high/max，保留本项目已实测的 Responses 接入。其他模型按资料指定协议处理，增加 Chat Completions 和其完整工具参数流校验。

上下文编译按模型 contextWindow 分配，并预留 maxOutput，不再固定缩减到 70%。自定义模型使用用户填写的上限。1M 是 provider profile 的上限声明，token 使用量仍为保守估计；本轮没有发送百万 token 的收费云端请求来测量容量。

未测试过的模型在第一次任务前自动检查连接；检查串行协调，正常任务可并行。文字模型检查文字与工具，支持图片的模型另检查图片输入和图片工具回传。检查记录按连接修订、模型 ID 和协议保存；不同模型不互相冒用结果。首次检查不会清除用户待发送的图片。

## 并行与继承

Native 最多接纳 8 个不同会话，每个会话至多一个活动运行。每次运行拥有自己的 Pi Runtime、模型/思考强度快照、网络适配器、授权 lease、工具发布集合、快照、取消与请求去重状态。停止、能力撤销和结束只清理对应运行；连接失效、宿主退出和存储失败仍会整体撤销，不在后台盲目继续设备动作。

物理设备是共享资源，实际工具动作串行执行；等待用户批准不占用执行器，其他会话的工具仍可运行。灰名单和 Skill/文件写入仍绑定具体操作确认，原 ADB 黑白灰名单不变。

新会话复制上次选择的能力、模型、思考强度和 Skill 挂载选择；不复制消息、历史、草稿或待发送图片。草稿按会话保留，后台任务发送失败不会把文字放进正在查看的另一个会话。

## 验证范围

测试覆盖与原始证据将在最终模拟器回归完成后写入 `tests/ui-redesign-evidence/`。本轮使用受控模型与搜索服务替代远端响应，实际运行 Android WebView、Native Fetch、SQLite、授权与 UI；不冒充真机或逐模型云端验收。已公开拉取当前 Pi 目录，核对 DeepSeek V4.1 Flash 的 1M 和 low/high/max。

可复现入口：根目录 `npm run verify`；`node scripts/ui-layout-check.mjs` 检查 620×540、620×180、360×640 布局；专用 AVD 上运行 `scripts/emulator-verify.py --serial emulator-5554 --lab-display 实际_OVERLAY_ID --output 独立证据目录`。模型 fixture 会替换可丢弃 AVD 中的测试连接资料，禁止在真机或真实资料安装中执行。
